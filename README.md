# Starry_Stellar
Welcome to the **Starry Stellar** 3D Space Museum project for the NASA Space Apps Challenge!

## Prerequisites
Before running the project, ensure you have the following installed:
* [Node.js](https://nodejs.org/) (LTS version recommended)
* [Python 3.x](https://www.python.org/)
* [Git](https://git-scm.com/)

## How to Clone and Run Locally

1. **Clone the repository**
   Open your terminal or PowerShell and run:
   ```bash
   git clone [https://github.com/salminnizam1102-cloud/Starry_Stellar.git](https://github.com/salminnizam1102-cloud/Starry_Stellar.git)
   cd Starry_Stellar
2.Install frontend dependencies & build the React app

Bash
npm install
npm run build
(Note for Windows PowerShell users: If you see a script execution error when running npm, run Set-ExecutionPolicy RemoteSigned -Scope CurrentUser first and confirm with Y).

3.Install Python dependencies & start the server

Bash
pip install flask
python homepage.py

4.Launch the 3D Museum
Open your web browser and navigate to the local URL shown in your terminal (typically http://127.0.0.1:5000 or http://localhost:8000).
